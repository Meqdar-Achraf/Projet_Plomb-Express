# Projet_Plomb-Express

## 📌 Présentation du projet

**Plomb Express** est un projet de création d'un site web
développé dans le but de présenter des services de plomberie
de l'entreprise Plomb'Express.

Le site propose une interface web permettant aux visiteurs
de découvrir les services proposés et de consulter les
informations disponibles.

## 🎯 Objectifs du projet

- Créer un site web clair et facile à utiliser.
- Présenter les services de plomberie.
- Organiser les informations de manière structurée.
- Concevoir une interface agréable et accessible.
- Mettre en pratique les connaissances en HTML et CSS.

## 🛠️ Technologies utilisées

Les technologies utilisées dans le projet sont :

- **HTML5** : structure des pages web.
- **CSS3** : mise en forme et design de l'interface.

## 📂 Structure du projet

```text
Projet_Plomb-Express/
│
├── Images/
│
├── css_files/
│
├── acceuill.html
├── service.html
├── contact.html
│
└── README.md
```


- `Images/` : dossier des ressources visuelles du site.
- `css_files/` : dossier des feuilles de style CSS.
- `acceuill.html` : page d’accueil (nom conservé tel qu’il apparaît dans le dépôt).
- `service.html` : page présentant les services.
- `contact.html` : page de contact.
- `README.md` : documentation du projet.
